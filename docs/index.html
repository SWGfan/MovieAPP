🎬 MovieAPP

A personal media hub for your own collection — a desktop app that catalogs local movies with posters & details from TMDB, and can launch your emulators too.

Electron + React TMDB metadata Local-first Open source
▶ Watch Now View on GitHub →

"Watch Now" streams directly from Nick's home PC and requires a personal access code — only works while that PC is on.

What it does

Movie library

Scans your local Movies folder and builds a browsable, searchable library with posters and details pulled from TMDB.

One-click playback

Click a movie and it opens in your system's default player — no re-encoding, no lock-in.

Emulator launcher

Point it at your emulators and your own legally-owned ROMs, and launch them from the same interface.

Status

This project is under active development. Progress and next steps are tracked on the GitHub Project board.
